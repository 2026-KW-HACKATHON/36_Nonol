# 매니패스트 산출물의 사용자 기준 교정 기록

작성일: 2026-09-28
수정 대상: 최상위 기능명세서, 유저플로우, 새_플로우_1.html 및 발표 GT와 전략.
변경 주체: 사용자의 후속 결정을 반영한 에이전트 수정. 매니패스트가 자동으로 수정한 결과라고 소개하지 않는다.
외부 상태: 매니패스트 서비스 내부 문서는 이번 작업에서 수정하지 않았다.

## 1. 교정의 근거

사용자 확정 내용:

- 참가비는 1인 10,000원이며 전액 결식 아동 후원.
- 미션을 수행한 뒤, 다음 장소로 떠나기 전 현장에서 NFC 태그로 마무리.
- 폰에서 미션과 다음 진행을 안내.
- 포인트 제도 없음.
- 원본의 잘못된 내용을 노놀 기준으로 교정.

## 4. 화면 검증 결과

로컬 브라우저에서 수정 HTML의 동작을 확인했다. 실제 제품 서버나 NFC 태그, Base 연결 시험은 하지 않았다.

1. 참가비 화면에서 2명일 때 총 20,000원, 후원 대상 20,000원 전액이 표시되는 것을 확인했다.
2. 첫 미션 수행 전 NFC 성공과 실패 버튼이 비활성화된 것을 확인했다.
3. 수행 완료 상태로 전환하면 NFC 마무리 버튼이 활성화되었다.
4. 인증 실패 상태에서 미션 수행 상태가 유지되고 재시도 안내가 나타났다.
5. 첫 인증 성공 시 스탬프 대신 다음 장소 2가 안내되었다.
6. 두 번째 장소에서도 수행 후 인증을 거쳐 장소 3으로 진행했다.
7. 마지막 미션 수행과 인증을 마친 뒤에만 완료 스탬프 안내와 여권 기록이 표시되었다.
8. 후원 화면에서 참가비 전액 결식 아동 후원과 가입자당 팀 부담 기부가 구분되었다.
9. 브라우저 스크린샷에서 후원 화면의 글자 잘림 없이 읽을 수 있음을 확인했다.

## 6. 아직 확정하지 않은 것

실제 미션의 내용과 완료 판정 방식, 팀 전원 인증 조건, 스탬프 귀속, 참가 일정, 로그인과 관심사 온보딩의 구체적 정책, 결제 및 환불, 후원 기관과 집행 일정은 사용자 확인 전 확정하지 않았다. 시안의 수행 완료 버튼은 검토용 상태 전환이며 실제 판정 방식에 대한 결정이 아니다.

## 7. 활용 평가

매니패스트가 문제, 기능, 화면, 수용 기준을 정리하는 출발점을 제공했다. 그러나 가격과 기부, 미션 순서, 보상은 사용자 검토로 교정해야 했다. 따라서 발표에서는 "매니패스트 초안을 우리 운영 기준으로 검토하고 수정했다"고 설명할 수 있다. 외부 고객에 대한 문제 가설 검증이나 실제 제품의 재현성 시험을 완료했다는 의미는 아니다.

## 8. 모바일 반응형 후속 수정

사용자의 요청에 따라 같은 HTML 파일에 모바일 레이아웃을 추가했다. 760px 이하에서는 오른쪽 화면 목록 대신 상단의 화면 선택 메뉴를 사용한다. 메뉴와 현재 화면을 동기화하고, 시연 초기화도 모바일에서 사용할 수 있게 했다.

버튼은 모바일에서 전체 너비와 최소 높이 50px로 배치했다. 제목, 설명, 참가비 표, 코스 안내와 스탬프를 세로 화면에 맞춰 조정했다. 데스크톱 화면 목록과 기존 진행 규칙은 유지한다.

확인 결과:

- 390 × 844 뷰포트에서 소개, 참가비, 미션과 인증 결과 화면을 확인했다.
- 인원 3명 입력 시 총 참가비 30,000원과 후원 금액 30,000원 전액이 일치했다.
- 모바일에서도 미션 수행 전 NFC 버튼이 비활성화되고 수행 후 활성화되는 것을 확인했다.
- 인증 성공 후 다음 장소와 상단 화면 선택 메뉴가 함께 바뀌었다.
- 320 × 740 뷰포트에서 9개 화면 모두 가로 넘침이 없었다. 스크롤바를 제외한 DOM 가용 너비는 305px였다.
- 모바일 메뉴의 시연 초기화 후 소개 화면으로 돌아왔다.
- 뷰포트 설정을 해제하고 데스크톱 레이아웃이 유지되는 것을 캡처로 확인했다.

## 9. 사용자 평가와 가로 스크롤 탑 바

사용자는 완성된 와이어프레임이 생각했던 콘셉트와 일치하며 마음에 든다고 평가했다. 사용자의 지식 관리와 매니패스트의 기획 구체화가 합쳐져 와이어프레임을 성공적으로 만들 수 있었다는 설명을 주었다. 정확한 사용자 표현은 260928_0448_중간발표_GT_사용자원문.md의 원문 9에 보존했다.

이 피드백은 제품 기획 의도와 결과물이 일치한다는 사용자의 평가다. 최종 고객의 수요 검증과는 구분한다. 매니패스트의 생성 결과뿐 아니라 사용자 결정과 로컬 교정이 함께 기여한 과정으로 설명한다.

후속 요청에 따라 모바일 드롭다운을 좌우 스크롤 탑 바로 교체했다. 각 버튼으로 화면을 선택하며 현재 화면은 진한 배경으로 표시한다. 화면 내부 버튼으로 이동한 경우에도 선택 탭을 동기화하고 가로 스크롤 위치를 이동시켜 현재 탭이 보이게 했다. 모션 감소 설정에서는 즉시 이동한다.

390px 모바일 검증:

- 탑 바를 오른쪽으로 스크롤한 후 후원 화면을 선택했다.
- 탑 바 내부만 가로 스크롤되며 페이지 전체는 가로로 넘치지 않았다.
- 미션 수행 후 NFC 성공 화면으로 이동하면 인증 결과 탭이 선택되며 보이는 범위에 들어왔다.
- 드롭다운 요소가 제거되었음을 확인했다.
- 검증 후 뷰포트 설정을 복원했다.
