광운스퀘어에서 비마관 앞까지를 우이천으로 삼아 바닥에 경로를 고정합니다. 첫 시험은 이 구간 중 10~20m만 스캔해 주세요.

지도 스캔 전, 연결 모듈 준비

실제 현장의 AR 바닥 고정과 재인식은 아직 검증 전입니다.

필수 준비물

  • 스캔한 공간의 Map ID
  • Mattercraft 프로젝트
  • 현장에서 시험할 휴대폰

3단계 준비 체크

0/3 표시

  1. 01 공간 스캔과 Map ID

    가입과 앱 설치를 마쳤다면 Mapper에 로그인하고 하단 촬영 버튼으로 새 지도를 만듭니다. Manual 모드를 선택해 주세요.

    광운스퀘어에서 비마관 방향의 짧은 구간을 밝은 환경에서 걸으며 촬영합니다. 바닥과 함께 건물, 계단 등의 고정된 특징을 담고 사진끼리 약 절반이 겹치게 찍습니다. 같은 특징이 세 장 이상에 담기도록 다른 위치에서도 촬영해 주세요.

    촬영 완료 후 지도 이름을 NonolSquareBima01처럼 영문과 숫자로 정해 저장합니다. Mapper 2.0에서는 On Device에서 지도를 열고 upload로 서버에 올립니다. 기존 앱에서는 완료 표시 후 바로 업로드됩니다.

    Developer Portal에서 처리 상태가 done이 되면 Map ID를 복사하고 고정 코스 설정의 Immersal Map ID에 저장합니다. 완성된 지도를 앱에서 내려받아 AR 및 Localize로 같은 장소의 재인식을 확인합니다. Map ID 등록 후 Mattercraft 프로젝트를 연결하는 단계가 이어집니다.

    Mapper 2.0의 저장, AR 시험 및 업로드 화면 ↗ 겹치는 사진과 고정된 특징 촬영 안내 ↗ 공식 스캔 안내와 설치 링크 ↗

  2. 02 프로젝트 연결과 경로 배치

    Mattercraft의 Immersal Blank (with Splash) 템플릿을 엽니다. 본인의 프로젝트에서 ImmersalAnchorGroup에 Developer Token과 Map ID를 설정합니다.

    아래 연결 소스를 사용해 맵 좌표에 경유점과 바닥 화살표를 배치합니다. 미리 지정한 경로를 시험하며 실시간 경로 자동 계산은 제공하지 않습니다.

    개발 토큰은 본인 Mattercraft 프로젝트에서 설정해 주세요. 이 페이지는 토큰을 입력받거나 저장하지 않습니다.

    공식 프로젝트 연결 안내 ↗

  3. 03 현장에서 재인식 시험

    스캔한 구간에서 휴대폰으로 프로젝트를 열고 같은 공간을 다시 인식하는지 확인합니다. 걸으며 바닥의 경로가 같은 위치에 유지되는지 시험해 주세요.

    다른 각도와 조명에서도 재인식과 바닥 고정을 확인합니다.
