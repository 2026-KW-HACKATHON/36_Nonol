# Test Lab 공개 작업 기록

갱신 시각: 2026-10-09 06:37:19 KST

팀 모바일 퀘스트 시험 도구의 완료 사항과 검증 범위를 기록한다. 실행 및 배포 안내는 [README.md](README.md), 규칙 원본은 [test-track.json](public/test-track.json), 운영 서비스 경험은 [서비스 흐름 SSOT](../game/docs/261009_0313_서비스흐름_정책_SSOT.md)를 따른다.

## 팀 방과 진행 공유

같은 링크로 입장하고 전원 준비 후 팀장이 시작하는 방을 구현했다. 첫 입장자가 팀장이며 권한을 다른 참가자에게 양도할 수 있다. 일반 시험 방은 한 명도 준비 후 시작하고 인원 상한을 두지 않는다. 참가자, 준비와 현재 단계를 WebSocket으로 공유하며 재접속 시 서버 상태를 복구한다.

팀장은 이전 및 다음 단계 이동과 현재 단계 초기화를 실행한다. 전체 초기화는 같은 링크에서 입장부터 다시 시작하고 관리자 삭제는 방 데이터와 접속을 종료한다. 실행 ID와 요청 ID로 이전 비동기 결과 및 중복 요청이 새 진행에 섞이지 않도록 처리했다.

## 독립 모듈 시험

지도, 사진 인식, 묵언 신고, 정령, AR 길, 거리와 방향 탐색 및 벌점 정산을 연결했다. 시작 후 팀장이 해당 모듈의 위치, 반경 또는 기준 사진을 설정하며 팀장과 팀원이 같은 설정으로 시험한다. 모듈 선택과 설정은 준비 단계와 분리했다.

지도는 실제 GPS가 목적지 원 안에 들어왔는지 검사하고 사진은 독립적으로 기준 물체 인식을 시험한다. 사진 촬영과 이미지 선택을 구분하며 기준 사진 교체 시 기존 판정을 취소한다. 신고는 요청마다 즉시 벌점을 반영하고 재전송은 한 번만 집계한다. 정령 생성과 터치 후 개인별 이야기를 진행하고 최종 화면에서 개인과 팀 벌점 및 벌점 왕을 확인한다.

가상 좌표 조작과 가상 사진 판정을 제거했다. GPS는 측정 시각을 사용하며 30초를 넘거나 허용 범위를 벗어난 미래 측정을 도착 판정에 사용하지 않는다. 측정이 멈추거나 화면이 복귀하면 새 위치를 요청한다. 오래된 방향과 카메라 및 AR 요청은 단계 변경과 초기화에서 정리한다.

## 고정 코스와 지도 선택

학교 코스의 장소 역할을 복지관은 이층집, 광운스퀘어는 우이천 초입, 광운스퀘어에서 비마관 앞까지는 우이천, 비마관 앞은 솥고집 정령, 풋살장은 카페로 정의했다. 정령 이야기를 마친 뒤 지도 없이 카페를 탐색하고 도착 후 벌점 정산을 확인한다.

관리자는 /tracks에서 지도 핀으로 네 장소를 선택하고 반경과 실제 에어팟 원본을 등록한다. 위도와 경도 직접 입력을 제거하고 현재 위치, GPS 오차, 내 위치 보기 및 현재 위치로 지정 버튼을 제공한다. 위치 갱신은 선택 핀과 반경 입력 및 포커스를 유지하며, 현재 위치 측정만으로 등록 장소나 도착 기록을 바꾸지 않는다.

새 방은 생성 당시 코스, 사진 및 스토리 버전을 보관한다. 이후 코스 수정은 기존 방을 바꾸지 않는다. 고정 방의 설정은 읽기 전용이고 전체 초기화 후에도 같은 코스를 유지한다. 오래된 버전으로 저장하거나 방을 생성하면 거절한다. 고정 코스의 사진 인증은 해당 참가자의 지도 도착 기록도 확인한다.

## 개인 링크와 노놀판 시험

관리자가 시험용 신청 명단과 개인 링크를 발급하고 각 참가자가 노놀판 확인과 준비 후 시작하는 흐름을 구현했다. 링크 소지로 참가자를 구분하며 회원가입을 요구하지 않는다. 서버에는 초대 정보의 해시를 저장한다.

현재 명단은 관리자가 시험용으로 생성한다. 실제 신청 데이터, 결제와 카카오톡 자동 발송은 연결하지 않았다. 노놀판 URL의 확인 버튼으로도 기록이 생성되므로 이 시험은 물리적 NFC 접촉 자체나 주문 완료를 증명하지 않는다.

## 카카오 지도와 공간 AR

카카오 지도 SDK와 공통 지도 어댑터를 적용하고 키 또는 연결이 준비되지 않으면 대체 지도와 설정 상태를 표시한다. 실제 배포 사이트의 새 브라우저에서 SDK HTTP 200, 카카오 타일 로딩, 현재 위치와 오차 및 지도 클릭을 확인했다. 키 값은 코드와 문서에 포함하지 않는다.

정령은 기기별 공간 AR과 2D 대체를 제공한다. 바닥 경로는 Mattercraft와 Immersal 공간 스캔을 사용하는 연결 소스와 준비 화면을 제공한다. 추적 손실과 화면 전환 시 경로 및 완료 처리를 보류하고 새 인식 후 이어가는 로직을 검증했다. 카메라 방향 안내와 GPS 경유점 확인은 실제 바닥 고정 성공과 구분한다.

## 검증한 범위와 다음 현장 시험

단위 테스트, 실제 Worker의 WebSocket 시험과 모바일 브라우저 QA에서 팀 동기화, 재접속, 설정 공유, 사진 판정 격리, 연속 신고, 단계 조작, 초기화와 삭제를 확인했다. 320px, 360px 및 390px 화면에서 지도와 입력 배치, 포커스 유지, 타일 로딩과 가로 넘침을 점검했다. 실제 카카오 SDK 연결도 확인했다. 검증용 방과 자료는 공개 코드에 포함하지 않는다.

브라우저 QA의 GPS, 카메라와 AR 요청 모사 결과는 실제 휴대폰의 이동 및 공간 추적 성공과 구분한다. 현장에서 확인할 항목은 GPS 도착 정확도와 화면 잠금 후 복구, 나침반 보정, 사진의 각도 및 조명별 오인식, Android와 iPhone 정령 추적 및 터치, NFC 브라우저 복귀, 공간 스캔 후 바닥 경로의 정합이다.

바닥 고정 AR은 실제 구간 스캔, Map ID와 Mattercraft 프로젝트를 확보해 현장 재인식을 시험해야 한다. 운영 적용은 현장 검증한 모듈부터 실제 장소와 신청 및 완주 흐름에 연결한다.
