# 팀 대기실 정책 SSOT

정책 ID: nonol-room-v1
사용자 확정 시각: 2026-10-08 12:37:27 KST

정책 원본은 public/room-policy.json이다. 서버가 이 파일을 직접 사용하고, 이 문서는 npm run policy:render로 원본에서 생성한다. 정책 수정은 사용자 합의 후 원본에 적용하고 문서를 다시 생성한다.

## 확정한 정책

| ID | 정책 |
| --- | --- |
| ROOM-01 | 방의 참가 인원에 상한을 두지 않는다. |
| ROOM-02 | 처음 입장을 완료한 참가자가 최초 팀장이 된다. |
| ROOM-03 | 참가자는 준비 전 상태로 입장하고, 팀장도 자신의 준비 상태를 직접 선택한다. |
| ROOM-04 | 현재 팀장이 다른 참가자에게 팀장 권한을 넘기면 양도자의 준비가 해제된다. |
| ROOM-05 | 팀장 권한을 받은 참가자의 기존 준비 상태를 유지한다. |
| ROOM-06 | 전체 참가자가 준비 완료일 때 현재 팀장만 트랙 시작하기를 실행한다. |
| ROOM-07 | 서버가 팀장, 준비 및 시작 상태를 확정하고 WebSocket으로 전체 참가자에게 전달한다. |
| ROOM-08 | 같은 브라우저의 재접속은 동일 참가자와 최신 팀 상태를 복구한다. |
| ROOM-09 | 참가자는 전달받은 팀 링크로 입장하며, 참가자에게 방 생성과 링크 전달 작업을 요구하지 않는다. |

## 적용 범위

첫 개발은 팀 링크 입장, 준비 상태, 팀장 양도, 트랙 시작 및 재접속 복구다. 카카오톡 자동 발송, 위치 지도, 사진 판정, AR 및 후속 미션은 이번 코드에 포함하지 않는다.

## 확인 대기

게임 시작 후 신규 참가자 입장 정책은 사용자 답변을 기다리고 있다. 이번 개발은 시작 전 신규 입장과 기존 참가자의 재접속을 제공하며, 시작 후 신규 입장은 아직 구현 범위에 포함하지 않는다.

## 변경 검증

정책을 바꾸면 상태 단위 테스트, 실제 WebSocket 통합 테스트 및 브라우저 사용 흐름을 확인한다. 참가 인원은 고정된 숫자 대신 방에 등록된 참가자를 기준으로 계산한다.
