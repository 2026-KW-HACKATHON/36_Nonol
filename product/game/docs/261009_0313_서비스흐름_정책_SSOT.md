## 미입장 NFC 안내의 기술 확인

가능한 방식은 노놀판에 장소 식별자를 포함한 HTTPS 주소를 NDEF URI로 기록하고, 휴대폰이 연 웹페이지에서 입장 정보를 확인해 안내를 분기하는 것이다. iPhone XS 이후 지원 기기는 NFC 알림을 누르면 링크를 열 수 있고, Android도 NDEF의 웹 주소를 앱으로 전달한다. 열리는 브라우저와 알림 동작은 기기와 OS 설정에 따라 확인한다. [Apple 공식 안내](https://developer.apple.com/documentation/corenfc/adding-support-for-background-tag-reading?changes=_1&language=objc), [Android 공식 안내](https://developer.android.com/develop/connectivity/nfc/nfc).

입장 정보를 확인할 수 있으면 해당 참가자의 방과 노놀판을 연결한다. 확인할 수 없으면 카카오톡 안내 링크를 열도록 안내한다. 공통 노놀판 주소만으로 누구인지와 어느 방인지 알 수 없으므로, 실제 미입장 여부와 이 브라우저에서 복원할 수 없는 상태를 같은 안내로 다룬다. 카카오톡 메시지를 자동으로 읽거나 본인의 방 링크를 자동으로 찾는 기능을 전제로 하지 않는다.

카카오톡 내부 브라우저와 Chrome 또는 Safari는 입장 저장정보가 이어지지 않을 수 있다. 이미 방에 들어왔더라도 NFC가 다른 브라우저에서 열리면 안내 대상이 될 수 있다. 이 경우 전달받은 본인의 링크로 기존 참가자를 복원하는 흐름이 필요하다. 입장 후 원래 태그 화면으로 복귀하거나 태그를 다시 진행하는 선택은 후속 구현에서 확정한다.

현재 Test Lab은 /board?board=icheungjip-lab 주소에서 저장된 개인 입장 정보를 복원하고, 정보가 없으면 개인 링크 붙여넣기 양식을 제공한다. 사용자가 요청한 카카오톡 링크 안내 문구는 아직 구현하지 않았다. 현재 확인 기록은 노놀판 확인하기 버튼의 요청으로 생성하며, 물리적 NFC 접촉이나 커피 주문 완료를 자동 증명하지 않는다.

확인한 코드: game-lab/public/261009_0320_board.js의 restoreIdentity와 노놀판 요청, game-lab/src/worker.js의 boardUrl, game-lab/src/game-room.js의 전원 확인 조건.
