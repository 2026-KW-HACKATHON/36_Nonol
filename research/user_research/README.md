# 유저 리서치

노놀의 설문과 인터뷰 같은 사용자 조사를 모으는 폴더다. 조사 한 건마다 폴더 하나를 만든다.

## 폴더 규칙

- 조사 폴더 이름: `YYMMDD_HHMM_조사이름`
- 폴더 안 파일도 `YYMMDD_HHMM_` 접두어를 붙인다.
- 조사 한 건의 기본 구성
  - 설문_설계.md: 조사 목적, 문항과 보기, 설계 의도, 분석 계획
  - 결과.md: 응답자 수, 조사 기간, 배포 경로, 집계 결과 (조사 뒤 작성)
  - 모집_글.md: 채널별 링크와 올릴 글
  - site/: 설문을 받는 페이지가 있을 때 그 코드
- 응답 원자료에 개인정보가 들어 있으면 저장소에 올리지 않는다. 집계 결과만 올린다.

## 공통 설계 원칙

- 의견보다 행동을 묻는다.
- 판단 기준은 응답을 보기 전에 고정한다.
- 보기에는 긍정과 부정을 함께 넣는다.
- 질문지는 누구에게 보여도 되는 수준으로 만든다.
- 결과에는 응답자 수와 배포 경로를 함께 적는다.
