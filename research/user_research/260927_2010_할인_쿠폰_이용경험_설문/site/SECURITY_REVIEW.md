# 설문 DB 연결 및 공개 접근 점검

점검일: 2026-09-27 (KST), 배포 후 재검증: 22:49

## 결론

현재 운영 중인 coupon-survey Worker는 Cloudflare D1의 nonol-survey에 연결돼 있다. 실제 배포된 Worker 코드를 내려받아 확인했고, 인증하지 않은 외부 요청과 로컬 회귀 테스트에서 저장된 응답 및 휴대폰 번호를 조회하는 공개 경로는 확인되지 않았다.

localhost:8792 미리보기는 별도의 로컬 D1을 사용한다. 최초 점검 당시에는 새 디자인과 복수 선택 개편이 미배포 상태였으며, 이후 사용자 요청에 따라 아래와 같이 운영 배포와 재검증을 완료했다. 응답 내용과 휴대폰 번호는 조회하지 않았다.

## 배포 코드와 개편 코드 검토

- 실제 배포된 코드는 인증된 Cloudflare 관리 API로 받아 확인했다. API 라우트는 survey, respond, raffle 세 개뿐이다.
- 데이터베이스 작업은 매개변수를 바인딩한 INSERT 두 개다. SELECT나 저장된 값을 반환하는 RETURNING이 없다.
- 응답 및 추첨 저장 결과는 { ok: true }만 반환한다. 번호가 이미 등록됐는지에 따라 응답을 바꾸지 않는다.
- 실제 집계와 추첨은 public 밖의 scripts에서만 수행한다. 배포되는 정적 파일 경로는 public이다.
- 오류 응답에 입력값이나 DB 세부 오류를 넣지 않는다. 애플리케이션 로그는 경로와 오류 종류만 남긴다.
- 응답과 번호는 별도 테이블에 저장하며 공통 응답 식별자를 사용하지 않는다.
- 개편 코드에서도 동일한 공개 접근 정책을 유지한다. 추가된 services는 서버 저장 필드이며 조회 API가 추가되지 않았다.

## 자동 검증

test/security.test.js에 공개 API의 DB 미조회, 읽기 및 관리 경로 거절, 외부 Origin 거절, 입력값 비반사, 저장 결과 최소화, 중복 번호의 동일 응답, DB 오류 비노출을 검증하는 테스트 4개를 추가했다.

전체 테스트 18개와 문법 검사가 통과했다. 테스트의 전화번호는 메모리 모형 DB에서만 사용했으며 운영 추첨 DB에는 제출하지 않았다.

## 범위와 남은 사항

이 결론은 점검 당시 해당 Worker와 D1의 공개 접근 경로에 관한 것이다. Cloudflare 계정 권한이나 유효한 API 토큰을 가진 관리자는 DB를 읽을 수 있다. 계정 구성원 전체, 다른 Worker, 과거 유출이나 관리자 기기의 보안까지 검증한 것은 아니다.

Origin 검사는 관리자 인증이 아니다. 브라우저 밖의 프로그램은 Origin을 지정할 수 있다. 데이터 조회를 막는 핵심은 공개 조회 코드가 없고 Cloudflare 관리 API에 인증이 필요하다는 점이다.

응답 제출은 공개 기능이다. 코드에는 별도 요청 횟수 제한이나 봇 인증이 없고, 본문 크기 검사는 전체 본문을 읽은 뒤에도 수행된다. 대량 제출 및 과도한 요청으로부터 서비스와 통계를 보호하는 일은 데이터 열람 차단과 별도의 과제다. 계정 차원의 WAF 설정은 이번에 확인하지 않았다.

이번 배포에서는 원격 0002_services.sql 적용, Worker 배포, 비인증 접근 재검사를 모두 완료했다. 향후 변경 시에도 공개 조회 경로가 생기지 않았는지 다시 검증한다.
