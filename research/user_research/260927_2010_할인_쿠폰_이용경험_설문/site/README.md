- 주소: https://coupon-survey.1991knet.workers.dev
- 작성: 2026-09-27 (KW 해커톤 기간 중)
- 최근 운영 반영: 2026-09-27 22:49 KST, 새 디자인과 서비스 복수 선택 개편
- 구성: Cloudflare Workers, D1 (nonol-survey), 정적 파일은 public/

## 보안 원칙

이 사이트는 받기만 한다. 응답이나 번호를 돌려주는 주소가 인터넷에 없다.

- Worker 가 여는 주소는 세 개뿐이다: 문항 받기(GET /api/survey), 응답 보내기(POST /api/respond), 추첨 참여(POST /api/raffle). 셋 다 저장된 내용을 돌려주지 않는다.
- 결과 조회와 추첨은 Cloudflare 계정으로 로그인한 컴퓨터에서 scripts/ 의 스크립트로만 한다. 비밀번호를 넣는 결과 페이지는 두지 않았다. 비밀번호 페이지는 주소가 인터넷에 열려 있어 비밀번호가 새거나 뚫리면 끝이기 때문이다.
- 설문 화면에 팀 이름, 대회 이름, 학교 이름을 적지 않는다.
- 응답 표에는 이름과 연락처가 없다. 휴대폰 번호는 별도 표에 두고 응답과 이어 붙일 수 있는 값을 두지 않는다.
- 보내는 요청은 같은 페이지에서 온 것만 받고(Origin 검사), 보기는 정해진 값만 받으며, 본문은 8KB 까지만 읽는다.
- 오류 기록에 입력값을 남기지 않는다.
- 화면에는 CSP, 프레임 금지, 검색 제외 머리말을 붙였다 (public/_headers).

## 동작

1. 한 화면에 한 문항씩 묻는다. 최대 10문항이고, 써 본 적이 없다고 답하면 2문항으로 끝난다.
2. 이용해본 서비스를 복수 선택한다. 여러 개를 골랐을 때만 그중 가장 많이 이용한 하나를 추가로 묻는다. 하나만 골랐다면 그 서비스를 이후 응답의 기준으로 정한다.
3. 덜 쓴다 또는 이제 안 쓴다고 답한 사람에게만 이유를 묻는다.
4. 끝 화면에서 원하는 사람만 휴대폰 번호를 남겨 추첨에 참여한다.
5. 링크는 하나로 통일해 돌린다. 주소에 `?from=` 값을 붙이면 유입 경로를 셀 수 있지만 지금은 쓰지 않는다.

복수 선택은 `services`, 이후 응답의 기준 서비스는 기존 `service` 열에 저장한다. `service_other`는 복수 선택에서 기타를 고른 경우의 설명이다. 이전 화면에서 제출한 단일 선택 응답도 받으며, 개편 전 응답의 `services`는 빈 값으로 남긴다. 이용해본 서비스 통계는 복수 선택 문항에 답한 사람만 분모로 삼는다.

`0002_services.sql`은 운영 DB에 적용됐다. 기존 응답을 보존하고 새 열만 추가했다. 이후 `npm run deploy`도 마이그레이션을 먼저 실행한다.

## 파일

| 파일 | 내용 |
| --- | --- |
| src/survey.js | 문항 정의, 입력 검사, 집계. 문항을 고치려면 이 파일을 고친다 |
| src/worker.js | 응답 저장, 추첨 참여 |
| public/ | 설문 화면 |
| scripts/results.mjs | 집계 보기 (내 컴퓨터에서만) |
| scripts/draw.mjs | 추첨과 번호 삭제 (내 컴퓨터에서만) |
| migrations/ | D1 표 정의 |
| test/ | 분기, 입력 검사, 집계 시험 |

문항의 분기 규칙은 src/survey.js 의 path 와 public/app.js 의 path 두 곳에 있다. 고칠 때 함께 고친다.

## 명령

```bash
npm install
npm run dev        # http://127.0.0.1:8792
npm test           # 분기, 입력 검사, 집계, 화면 상태 시험
npm run check      # 문법 검사
npm run deploy     # 원격 DB 마이그레이션 뒤 배포

npm run results    # 집계를 터미널에 보여 주고 .local/ 에 md 로 저장
npm run draw       # 2명 추첨. 번호는 터미널에만 나온다
npm run purge      # 쿠폰을 보낸 뒤 번호 전부 삭제
```

집계 파일이 저장되는 .local/ 은 저장소에 올라가지 않는다. 직접 입력 칸에 개인정보가 없는지 본 뒤에만 결과 문서로 옮긴다.

## 개인정보

- 설문 답변은 익명이다.
- 휴대폰 번호는 추첨 참여에 동의한 사람 것만 받는다.
- 추첨과 쿠폰 발송이 끝나면 `npm run purge` 로 번호를 지운다.
- 응답 원자료와 번호는 저장소에 올리지 않는다.
