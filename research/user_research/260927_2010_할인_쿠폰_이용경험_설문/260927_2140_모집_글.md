## 인스타그램 (스토리)

링크 스티커에 설문 주소를 붙인다. 도와 달라는 부탁만 적는다.

```
도와주세요!

쿠폰이나 할인 받으려고 앱 써 본 적 있으신가요?
약 3분이면 끝나는 설문입니다.
써 본 적이 없어도 괜찮아요.
```

짧은 판

```
약 3분 설문, 도와주세요!
```

## 에브리타임

제목

```
[설문] 쿠폰, 할인 앱 써 본 경험 (추첨으로 스타벅스 쿠폰)
```

본문

```
쿠폰이나 할인을 받으려고 앱이나 서비스를 써 본 경험을 묻는 설문입니다.
(마감 할인, 타임 세일, 첫 주문 쿠폰, 스탬프 적립 등)

약 3분 소요, 답변은 익명입니다.
써 본 적이 없어도 참여할 수 있습니다.

참여해 주신 분 중 추첨을 통해 2명에게 스타벅스 쿠폰을 드립니다!

https://coupon-survey.1991knet.workers.dev

감사합니다.
```
