# 노놀 소개 영상 기획안 v1.0

- 작성일: 2026-09-16
- 산출물: promo/nonol-promo-42s-v1.mp4 (42.0초 무음), promo/nonol-promo-42s-v2-bgm-sfx-나레이션.mp4 (42.8초 최종, BGM과 나레이션 포함). 1920x1080 (16:9), 30fps, H.264. 2026-09-17 완성
- 용도: 모두의 창업 프로젝트 2차 도전신청서 Q5 (유튜브 링크, 공고 기준 숏폼 30초에서 60초). 이후 KW 해커톤 발표와 인스타그램 소개에도 재사용
- 레퍼런스: Guardian-Angel-Alert/csi-marketing 의 CSI-Guard 홍보 영상(35.6초, v6)과 그 제작 파이프라인. 원래 레퍼런스였던 PILLGOOD 어플 소개 영상(24초, 세로형)의 구성 흐름도 같이 따른다
- 제작 파이프라인: Playwright로 사이트 캡처 -> GSAP 타임라인 HTML(promo.html) -> 프레임 렌더(render.mjs) -> ffmpeg 인코딩 -> MusicGen BGM + 합성 효과음 + edge-tts 나레이션을 ffmpeg 사이드체인 더킹으로 믹싱

## 1. 레퍼런스에서 가져오는 것

- 구성: 로고 인트로, 문제 제기(타이포 중심), 솔루션 선언(목업 첫 공개), 기능 섹션 3개(제목 + 서브카피 + UI 시연), 브랜드 컬러 풀스크린 아웃트로
- 스타일: 흰 배경, 실사 촬영 없음, 굵은 고딕 타이포, 글자 단위 타이핑, 핵심 단어에 브랜드 컬러 하이라이트 박스, 기기 목업의 플로팅과 슬라이드 전환
- 차이: CSI-Guard는 노트북 목업이 중심이었지만 노놀은 모바일 앱이라 폰 목업이 중심이다. 노트북 목업은 소개 사이트와 스토리 사이트 캡처를 보여 주는 두 장면에만 쓴다

## 6. 제작 방법

- 편집 도구를 쓰지 않고 HTML + GSAP 타임라인을 프레임 단위로 렌더한다 (레퍼런스와 동일). 타임라인은 promo/promo.html, 렌더는 promo/render.mjs, 인코딩은 promo/encode.sh
- 폰 목업은 CSS로 그리고 피그마 PNG를 안에서 세로 스크롤한다. 노트북 목업은 CSS + 캡처 mp4
- BGM: MusicGen (facebook/musicgen-stereo-small, 로컬 MPS) 30초 생성 후 RMS 최저점에서 잘라 0.8초 등파워 크로스페이드로 잇는다 (레퍼런스의 BGM 루프 규칙 준수). 가중치 라이선스 CC-BY-NC 4.0이라 공모전과 발표 용도로만 쓴다
- 효과음: CSI-Guard에서 자체 합성한 whoosh, ding, hit, click 재사용 (저작권 자유)
- 나레이션: edge-tts. 성우는 ko-KR-SunHiNeural(여성)을 기본으로 하고 ko-KR-HyunsuMultilingualNeural(남성)을 대안으로 둔다
- 믹싱: 사이드체인 더킹(threshold 0.02, ratio 8, attack 10ms, release 350ms), 나레이션 1.25배, 리미터 0.95, 모든 스템 apad 후 atrim

## 7. 작업 순서

1. 사이트 캡처 (완료, 2026-09-16)
2. 기획안 (이 문서)
3. promo.html 타임라인 작성과 프레임 렌더, 무음 v1 출력 (완료, 2026-09-17)
4. BGM 후보 생성과 선택, 효과음 배치, 나레이션 생성 (완료, audio/노놀_소개영상_오디오작업_명세_v1.0.md)
5. 믹싱과 검증 (완료, v2)
6. 팀 리뷰 후 유튜브 업로드(미등록 링크), Q5에 첨부 (남음)

재렌더 방법: promo.html 수정 후 `bun render.mjs` (1260 프레임, 약 1분), `./encode.sh nonol-promo-42s-v1.mp4`, `cd ../audio && ./mix_promo.sh`. 나레이션 문구가 바뀌면 audio/gen_tts.sh의 NARR 배열을 고치고 다시 실행한다.
